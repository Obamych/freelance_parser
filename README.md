# freelance_parser
Сбор заказов с фриланс-бирж и просмотр через Telegram-бота.
парсер будет собирать информацию с несколько фриланс бирж, чтобы находились нужные для пользователя заказы

## Запуск на Windows
Открой PowerShell в папке проекта. При первой настройке выполни:
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Создай `.env` из `.env.example`, если его ещё нет. Открой `.env` и вставь токен своего бота после `BOT_TOKEN=`. Этот файл остаётся на компьютере, в Git хранится только `.env.example`.

При первой настройке отдельно запусти бота:
```powershell
.\.venv\Scripts\python.exe bot.py
```
Отправь ему `/id` в Telegram. Запиши номер чата в `.env` после `TELEGRAM_CHAT_ID=` и останови бота через `Ctrl+C`.

Для обычного запуска используй одну команду:
```powershell
.\.venv\Scripts\python.exe run.py
```
Оставь окно открытым. Сначала запускается API, после его ответа запускаются бот и автосбор. Автосбор сразу получает заказы, затем повторяет сбор с заданным интервалом. В Telegram отправь `/start`, затем выбери «Последние» или напиши `/search Blender`.

Если раньше запускал `api.py`, `bot.py` и `worker.py` в отдельных окнах, сначала останови их через `Ctrl+C`. Общий запуск не использует уже работающие процессы и не останавливает их при занятом порте. Если один из запущенных компонентов завершится, остальные тоже останавливаются, причина остаётся в окне. Остановка всего проекта: `Ctrl+C` в окне `run.py`.

`API_PORT` задаёт локальный порт. Для общего запуска оставь `API_URL` незаданным: бот и автосбор используют локальный API. Отдельный запуск `api.py`, `bot.py` и `worker.py` по-прежнему доступен; при таком запуске `API_URL` позволяет указать другой адрес API.

## Автоматический сбор

1. В запущенном Telegram-боте отправь `/id`. Запиши полученный номер в `.env` после `TELEGRAM_CHAT_ID=`.
2. В `.env` укажи `COLLECT_INTERVAL_MINUTES=10`.
3. Запусти весь проект командой:

```powershell
.\.venv\Scripts\python.exe run.py
```

Первый успешный сбор запоминает начальный список без рассылки старых карточек. Следующие сборы начинаются раз в 10 минут. Новые заказы отправляются в указанный личный чат. API и автосбор должны использовать одну SQLite-базу. Если цикл занял больше интервала, следующий начнётся сразу после его завершения.

SQLite хранит ссылки обработанных заказов отдельно для каждого чата. Обычный перезапуск сохраняет эти отметки. После ошибки отправки карточка остаётся для следующей попытки, если она ещё есть в свежей выдаче. Если процесс аварийно завершился после доставки сообщения, но до записи отметки в SQLite, возможен повтор одной карточки.

Вторая копия `worker.py` для той же базы не запускается. Для проверки логики без Telegram выполни `python -m unittest discover -v`.

## Просмотр следующих заказов

«Последние», кнопки Kwork и Freelance.ru в главном меню и `/search слово` показывают по 5 заказов. Если в списке есть ещё заказы, под последней карточкой появляется кнопка «Ещё». Она отправляет следующие 5, сохраняя выбранную биржу и поисковый запрос. В конце бот пишет, что заказы в списке закончились. Кнопка открытия заказа остаётся на каждой карточке.

Бот запоминает список на момент запроса, поэтому автосбор не сдвигает страницы. Чтобы получить обновлённую выдачу, нажми «Последние» или повтори поиск. Новый запрос заменяет прежний список. Повторное нажатие использованной кнопки не отправляет уже показанную страницу. Списки отдельных чатов независимы.

Список хранится в памяти бота 30 минут. После перезапуска, нового поиска или истечения этого времени старая кнопка предлагает открыть список заново. Если отправка следующей страницы оборвалась, повторное нажатие её кнопки продолжает с последней подтверждённой карточки. При сетевом сбое, когда Telegram принял сообщение, но подтверждение потерялось, возможен повтор одной карточки.

## Избранные заказы

Под карточками в выдаче и уведомлениях есть кнопка «В избранное». После сохранения она меняется на «Убрать из избранного». Повторное нажатие старой кнопки сохранения не создаёт дубликат. В главном меню нажми «Избранное» или отправь `/favorites`, чтобы посмотреть сохранённые заказы. В этом списке также работает кнопка «Ещё».

Избранное хранится в SQLite отдельно для каждого чата и сохраняется после перезапуска. Заказ остаётся в избранном, если пропал из первой страницы биржи или перестал считаться свежим. Это не подтверждает, что он ещё открыт: карточка показывает прежнее состояние и время проверки. После удаления из избранного уже показанная карточка остаётся в переписке; для обновления сохранённого списка нажми «Избранное» заново. Кнопки сохранения работают и после перезапуска бота.

## Описание, публикация и состояние заказа

Карточка показывает описание из публичной выдачи (до 700 символов), дату площадки, время обнаружения и последнего сбора. У Freelance.ru в выдаче может быть уже сокращённое описание. Полный текст доступен по кнопке «Открыть заказ». Дополнительные запросы к каждому заказу не выполняются.

Для Kwork используется `date_create`, для Freelance.ru абсолютная дата из карточки. Если часовой пояс не указан, дата показывается с подписью «время площадки», без пересчёта в МСК. Даты с часовым поясом, время обнаружения и последнего сбора выводятся по МСК. При отсутствии даты или описания бот сообщает об этом.

Состояние показывается на момент последнего сбора. Явные признаки Kwork дают «открыт» или «неактивен»; неактивные записи не попадают в свежую выдачу, но остаются в избранном. Без явного признака состояние «неизвестно». Исчезновение с первой страницы само по себе не означает закрытие. Для сохранённых заказов без свежей проверки больше суток выводится предупреждение. Новые поля добавляются в существующую базу при следующем сборе; данные и отметки уведомлений сохраняются.

## Фильтры уведомлений

Отправь `/start`, затем нажми «Настройки» или используй `/settings`. Бот покажет выбранные биржи, ключевые слова и состояние паузы. Кнопки «Только Kwork», «Только Freelance.ru» и «Обе биржи» задают источник автоматических уведомлений. По умолчанию выбраны обе биржи. Также доступны `/sources kwork`, `/sources freelance` и `/sources all`.

Для ключевых слов нажми соответствующую кнопку и введи, например, `/keywords Blender, Python, 3D модель`. В названии заказа должно встретиться хотя бы одно указанное слово или фраза. Регистр не учитывается, совпадение ищется как часть текста. Выбор биржи и ключевые слова применяются вместе. Доступно до 10 фраз общей длиной не больше 300 символов. Кнопка «Сбросить слова» или `/keywords_clear` убирает только фильтр слов.

Настройки сохраняются в SQLite для чата и действуют до следующего изменения. Все биржи продолжают собираться; фильтры ограничивают автоматическую отправку. «Последние», кнопки бирж в главном меню и `/search` работают с общей свежей выдачей. При смене фильтра подходящие неприсланные заказы из свежей выдачи могут прийти в следующем цикле; уже отправленные карточки не повторяются. Фильтры перечитываются перед каждой отправкой. Первое подключение чата по-прежнему запоминает начальный список без рассылки истории.

## Пауза уведомлений

В Telegram отправь `/start`, чтобы обновить кнопки меню. Кнопка «Пауза» или команда `/pause` приостанавливает автоматическую отправку. Кнопка «Возобновить» или `/resume` включает её снова. Управление доступно в личном чате, указанном в `TELEGRAM_CHAT_ID`.

Сбор продолжается каждые 10 минут, просмотр через «Последние» и поиск работают. Настройка хранится в SQLite отдельно для чата и сохраняется при перезапуске. При паузе во время рассылки уже начатая отправка одной карточки может завершиться, следующая не начинается.

После возобновления автосбор в следующем цикле отправляет неприсланные заказы, которые ещё есть в свежей выдаче. Подтверждённые отправки не повторяются. Состояние паузы видно в `/status`; оно показывается отдельно от состояния сбора.

## Статус в Telegram

Команда `/status` и кнопка «Статус» показывают последний итог сбора, число полученных заказов по каждой бирже, дату её последнего успешного сбора и общее число новых записей. Если биржа вернула ошибку, её прежний успешный сбор не выдаётся за текущий.

Ниже показаны последняя запись автосбора, количество подтверждённых уведомлений за текущий цикл, ошибка отправки и время следующего сбора по плану. Время выводится по МСК. Статус хранится в SQLite и сохраняется после перезапуска. Это сохранённое состояние, а не проверка работающего процесса: если плановое время прошло, бот предлагает проверить окно `run.py`. После аварийного закрытия окна последняя запись может остаться прежней.

## Обновление заказов
При общем запуске заказы обновляет автосбор. Для разового сбора можно отдельно запустить `parser.py`. В выдаче используются карточки с последних успешно собранных первых страниц бирж. Записи, которые больше не попали на эту страницу, остаются в базе. Само по себе исчезновение с первой страницы не подтверждает закрытие заказа. Архивные проекты Kwork исключаются, если площадка отдала этот признак.
В карточке показывается время последнего сбора. Если сбор не выполнялся больше суток, сохранённые карточки перестают попадать в выдачу до следующего успешного сбора. При ошибке одной площадки её предыдущий список сохраняется до истечения этого срока, вторая площадка обрабатывается независимо. Заказ может закрыться между сбором и просмотром, состояние проверяется по кнопке "Открыть заказ".
