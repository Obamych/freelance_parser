# freelance_parser
Сбор заказов с фриланс-бирж и просмотр через Telegram-бота.
парсер будет собирать информацию с несколько фриланс бирж, чтобы находились нужные для пользователя заказы

## Запуск на Windows
Открой PowerShell в папке проекта. При первой настройке выполни:
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Создай `.env` из `.env.example`, если его ещё нет. Открой `.env` и вставь токен своего бота после `BOT_TOKEN=`. Этот файл остаётся на компьютере, в Git хранится только `.env.example`.

Собери заказы:
```powershell
.\.venv\Scripts\python.exe parser.py
```
Запусти API и оставь это окно открытым:
```powershell
.\.venv\Scripts\python.exe api.py
```
Во втором окне PowerShell из той же папки запусти бота:
```powershell
.\.venv\Scripts\python.exe bot.py
```
В Telegram отправь `/start`, затем выбери «Последние» или напиши `/search Blender`.
`API_PORT` задаёт локальный порт. Если API и бот работают на одном компьютере, бот сам использует этот порт. `API_URL` пригодится, если бот подключается к API по другому адресу. Настройки чата и интервала в примере пока закомментированы: они понадобятся при добавлении автоматической отправки.

## Обновление заказов
Перед просмотром запусти `parser.py`. В выдаче используются карточки с последних успешно собранных первых страниц бирж. Записи, которые больше не попали на эту страницу, остаются в базе. Само по себе исчезновение с первой страницы не подтверждает закрытие заказа. Архивные проекты Kwork исключаются, если площадка отдала этот признак.
В карточке показывается время последнего сбора. Если сбор не выполнялся больше суток, сохранённые карточки перестают попадать в выдачу до следующего успешного сбора. При ошибке одной площадки её предыдущий список сохраняется до истечения этого срока, вторая площадка обрабатывается независимо. Заказ может закрыться между сбором и просмотром, состояние проверяется по кнопке "Открыть заказ".
